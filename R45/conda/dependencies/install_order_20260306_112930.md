# R-bio 包安装顺序分析

## 1. 系统依赖 (必须先安装)

```bash
# 构建工具
build-essential cmake curl wget git libtool pkg-config

# R 开发库
libcurl4-openssl-dev libssl-dev libxml2-dev libbz2-dev liblzma-dev zlib1g-dev
libhdf5-dev libglpk-dev libgit2-dev libffi-dev

# Python 开发库
libncurses5-dev libreadline-dev libsqlite3-dev
```

## 2. R 包依赖层级

### Level 0: 核心基础包 (Bioconductor 基础设施)
- BiocManager
- BiocVersion
- S4Vectors
- IRanges
- GenomicRanges
- GenomeInfoDb
- Biobase
- BiocGenerics
- BiocParallel

### Level 1: 数据结构包
- SummarizedExperiment
- SingleCellExperiment
- DelayedArray
- HDF5Array
- MatrixGenerics
- DelayedMatrixStats

### Level 2: 注释数据库
- AnnotationDbi
- org.Hs.eg.db
- org.Mm.eg.db
- BSgenome
- BSgenome.Hsapiens.UCSC.hg38
- BSgenome.Mmusculus.UCSC.mm39

### Level 3: 分析工具基础
- limma
- edgeR
- DESeq2
- scran
- scater

### Level 4: 单细胞分析核心
- Seurat (依赖: SeuratObject, spatstat, Rcpp, etc.)
- Signac (依赖: Seurat, GenomicRanges, etc.)
- SingleR (依赖: SingleCellExperiment, etc.)

### Level 5: 空间转录组
- Giotto (依赖: Seurat, SingleCellExperiment, etc.)
- squidpy (Python)

### Level 6: 高级分析
- CellChat
- monocle3
- scVI/scvi-tools (Python)

## 3. Python 包依赖层级

### Level 0: 核心库
- numpy
- scipy
- pandas
- matplotlib

### Level 1: 机器学习
- scikit-learn
- numba

### Level 2: 单细胞分析
- scanpy (依赖: anndata, h5py, etc.)
- anndata

### Level 3: 深度学习
- torch
- scvi-tools

### Level 4: GPU 加速 (可选)
- cupy
- rapids-singlecell

## 4. 安装顺序建议

```
1. 系统依赖
   ↓
2. R 核心包 (Level 0-1)
   ↓
3. Python 核心包 (Level 0-1)
   ↓
4. R 注释数据库 (Level 2)
   ↓
5. R 分析工具 (Level 3)
   ↓
6. R 单细胞核心 (Level 4)
   ↓
7. Python 单细胞 (Level 2)
   ↓
8. R 空间转录组 (Level 5)
   ↓
9. R 高级分析 (Level 6)
   ↓
10. Python 深度学习 (Level 3-4)
```
